## 📖 Acerca del Proyecto

La **Plataforma Educativa Pequeños Científicos** es una iniciativa de vinculación e innovación educativa impulsada por la **Universidad Politécnica Salesiana (Sede Cuenca)**. Su objetivo es fomentar vocaciones en ciencia, tecnología, ingeniería y matemáticas (**STEM**) en niños y jóvenes de **10 a 18 años** mediante metodologías prácticas, lúdicas e interactivas.

El ecosistema integra una **estética inmersiva de cabina espacial / sci-fi**, laboratorios paso a paso, simuladores interactivos, y portales informativos para colegios e instituciones interesadas en convenios educativos.

---

## 🪐 Talleres Formativos

### 1. Taller de Ciencias Tecnológicas
- **Duración:** 2 semanas (10 días lectivos).
- **Enfoque:** Aprender haciendo mediante 4 mundos temáticos:
  - ⚡ **Mundo Eléctrico:** Circuitos, conductividad, fuentes de energía y leyes fundamentales.
  - 🧲 **Mundo Magnético:** Campos magnéticos, electromagnetismo y aplicaciones mecánicas.
  - 🌱 **Mundo Verde:** Energías renovables, sostenibilidad ecológica y bio-tecnología.
  - 💻 **Mundo Digital:** Lógica computacional, sensores, microcontroladores y programación.

### 2. Taller de Robótica Educativa (VEX IQ 2.0)
- **Duración:** 2 semanas (10 días lectivos).
- **Edad sugerida:** 12 a 18 años.
- **Enfoque:** Diseño estructural de robots móviles, cinemática, trenes de engranajes, sensores inerciales y programación autónoma y por radiocontrol.

## ✨ Características Principales

- 🚀 **Cabina de Misión:** Interfaz de laboratorio espacial con visor de videos demostrativos, pasos sincronizados y modo libre.
- 🤖 **Integración VEX IQ:** Experimentos adaptados con modelado y guías especializadas para robótica de competición y aula.
- 🔒 **Gestión Docente con Seguridad de Acceso:** Sistema de autenticación para docentes y administradores que protege la edición y calibración del contenido formativo.
- 🏛️ **Portal de Convenios Institucionales:** Enlace directo para que colegios y unidades educativas soliciten talleres para su alumnado redactando solicitudes formales a `pequeciencia@ups.edu.ec`.
- 💾 **Persistencia Local con IndexedDB:** Almacenamiento seguro en el navegador para guías y material multimedia de alta velocidad.
- 📱 **Diseño 100% Responsivo:** Optimizado tanto para pantallas interactivas de laboratorio, computadoras de escritorio y dispositivos móviles.

## 💻 Desarrollo Local

Si deseas clonar y ejecutar la plataforma en tu entorno local:

```bash
# 1. Clonar el repositorio
git clone https://github.com/PequeCiencia/plataforma-web.git

# 2. Entrar a la carpeta web
cd plataforma-web/web

# 3. Instalar dependencias
npm install

# 4. Iniciar servidor de desarrollo
npm run dev

# 5. Compilar para producción
npm run build
```

El servidor local se iniciará en `http://localhost:5173/`.
