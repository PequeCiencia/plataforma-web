# 🚀 Plataforma Educativa: Pequeños Científicos
### Universidad Politécnica Salesiana · Sede Cuenca

Plataforma didáctica e interactiva para la enseñanza de ingeniería, ciencias y robótica en estudiantes de 10 a 18 años. Diseñada con una estética inmersiva de cabina espacial, simulador de laboratorio y portales institucionales para colegios y docentes.

---

## 🌟 Escuadrón Científico (Mentores Oficiales)
- ⚡ **Dra. Electra**: Científica Líder & Mentora Experimental (Electricidad, Energía y Método Científico).
- 🧲 **Magno**: Especialista en Magnetismo & Física Mecánica (Fuerzas y Kits de Ingeniería).
- 🐒 **Astro**: Jefe de Prototipos & Curiosidad Práctica (Robótica, Taller y Prototipado).
- ✈️ **Cosmo**: Explorador Aeroespacial & Vuelo (Aerodinámica y Telemetría Espacial).
- 🤖 **Vector**: Arquitecto de Robótica, IA & Algoritmos (Programación por Bloques y Lógica).
- 🕷️ **Pixel**: Rover de Telemetría & Geología (Sensores Ultrasónicos y Exploración de Terreno).

---

## 🛠️ Tecnologías Utilizadas
- **React 19 + Vite 8**: Entorno ultra rápido y modular.
- **Lucide Icons & Canvas Confetti**: Interfaz de cabina futurista.
- **IndexedDB**: Almacenamiento local persistente de videos y guías multimedia en alta definición.
- **GitHub Actions & GitHub Pages**: Despliegue continuo y automático en la nube.

---

## 💻 Desarrollo Local

```bash
# 1. Instalar dependencias
npm install

# 2. Iniciar servidor de desarrollo
npm run dev

# 3. Compilar para producción
npm run build
```
